# Наш маленький мир — Telegram Mini App

Проект сохраняет исходный семейный сайт и добавляет Telegram Web App SDK, серверную синхронизацию и приватную админку.

## Что уже есть

- Все прежние разделы: «Наш день», «С малышом», «Только мы», «Забота о нас», «Наши моменты».
- Фильтры по участникам, настроению, бюджету и времени; подбор и сохранение идей.
- Семейные ритуалы: вопрос дня, традиция недели и «банка желаний».
- Telegram Web App SDK: открытие внутри Telegram и расширение на весь экран.
- Серверная синхронизация планов и воспоминаний; локальное хранение остаётся резервным режимом.
- Админка `/admin.html`: добавление/удаление идей, семейная статистика и рассылка через бота.
- Проверка подписи Telegram initData на сервере; админ-доступ ограничен Telegram ID из `ADMIN_IDS`.

## Переменные окружения

```env
BOT_TOKEN=токен_бота_от_BotFather
ADMIN_IDS=898467551
PORT=3000
```

**Не добавляйте BOT_TOKEN в файлы проекта и не отправляйте его в GitHub.** Добавьте его только в Secrets / Environment Variables хостинга.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
BOT_TOKEN="ваш_токен" ADMIN_IDS="898467551" npm start
```

Откройте `http://localhost:3000` для проверки обычной версии. Telegram авторизация и админка работают только по HTTPS внутри Telegram Mini App с корректным BOT_TOKEN.

## Публикация на Render

Создайте **Web Service**, а не Static Site:

- Repository: `D09081/123`
- Branch: `main`
- Root Directory: `our-little-world`
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/health`
- Environment: `BOT_TOKEN`, `ADMIN_IDS=898467551`

Для надёжного хранения семейных данных подключите постоянный диск и задайте `DATA_DIR` на путь диска либо подключите внешнюю БД. Сейчас MVP хранит данные в `data/family.json`; на хостингах с эфемерной файловой системой данные могут сброситься при пересоздании сервиса. Не используйте текущий файловый режим как единственную копию важных воспоминаний.

## Подключение к Telegram

1. Создайте бота через `@BotFather` командой `/newbot`.
2. Сохраните токен в секретах хостинга как `BOT_TOKEN`.
3. После публикации скопируйте HTTPS URL сервиса.
4. В `@BotFather` выберите `/mybots` → ваш бот → `Bot Settings` → `Menu Button` → `Configure menu button`.
5. Укажите текст кнопки, например `Наш мир ❤️`, и HTTPS URL сервиса.
6. Запустите бота командой `/start`, затем откройте Mini App через кнопку меню.
7. Админка открывается по адресу `https://ВАШ-ДОМЕН/admin.html` внутри этого же Mini App. Доступ будет только у ID из `ADMIN_IDS`.

Пользователь должен сначала открыть бота и Mini App, чтобы бот получил право отправлять ему личные сообщения. Рассылка в админке отправляется только пользователям, которые уже открывали приложение.

## Данные

Файловая база MVP находится в `data/family.json` и исключена из Git. Не храните в приложении медицинские сведения и другие чувствительные данные ребёнка. Перед эксплуатацией на нескольких устройствах подключите постоянное хранилище/БД и настройте резервное копирование.
