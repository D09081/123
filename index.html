Видеобалансеры

Internet Archive уже подключён без API-ключа: ищет видео с открытыми правами и прямыми MP4/WebM-потоками. Остальным источникам нужны отдельные совместимые адаптеры.

Cinema OS работает самостоятельно. Плагины Lampa не загружаются. Поддерживаются JSON API и Stremio Add-on Protocol. Добавляйте только источники, которыми вправе пользоваться.

Подключённые JSON-адаптеры

Адаптер должен принимать GET-запрос с параметром q и возвращать JSON-массив либо объект results. Каждый результат: title, url, type (video или iframe), rating (необязательно), quality (необязательно), voice (необязательно). Сервер адаптера должен разрешать CORS.

Добавить JSON-адаптер

Локальный адаптер принимает GET с параметром ?q= и возвращает JSON-массив либо объект results/items. Для Stremio Add-ons добавьте адаптер на сервере Render через переменную SOURCE_ADAPTERS: массив объектов с name, protocol:"stremio", url:"https://адрес-addon/manifest.json". Для обычного JSON API укажите protocol:"json", name и url. Ссылки должны вести на источники с законным доступом.

Настройки Cinema OS

Данные избранного и пользовательских источников сохраняются в памяти браузера телевизора.

Каталог и оценки IMDb

Cinema OS получает названия, постеры, описания и рейтинги IMDb через публичный каталог Cinemeta. API-ключ и регистрация не нужны. Рейтинг IMDb отображается отдельно от пользовательских оценок Cinema OS.

Источник каталога: Cinemeta / Stremio · источник рейтинга: IMDb

Cinemeta — публичный каталог Stremio; доступность и формат внешнего сервиса могут меняться. IMDb принадлежит правообладателю IMDb.

Встроенный плеер

Запускает прямые HTTP(S) видеопотоки, поддерживаемые браузером LG webOS/MSX. Ссылки на страницы сайтов и DRM-потоки могут не воспроизводиться.

О приложении

Cinema OS MVP · самостоятельная веб-оболочка для MSX Player / LG webOS.

Текущая версия содержит рабочую навигацию, поиск по каталогу Cinemeta, карточки найденных фильмов, избранное, настройки и запуск поддерживаемых прямых видео-ссылок. Подключение коммерческих/сторонних каталогов требует отдельных адаптеров и законного доступа к их API.
