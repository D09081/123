Онлайн-кинотеатр

Подключаем движок Lampa для поиска вариантов просмотра через совместимые плагины. После однократной установки нашего модуля Онлайн МОД загружается автоматически.

Поиск по реальной базе Кинопоиска. Добавьте API-ключ в настройках.

Видеобалансеры

Список подготовленных источников. Для реального поиска и воспроизведения каждому нужен совместимый адаптер API. Ничего не отмечено как подключённое без проверки.

Сторонние плагины Online MOD и Showy написаны для Lampa и не запускаются напрямую в самостоятельной HTML-оболочке. Для них нужен отдельный совместимый адаптер или Lampa runtime.

Подключённые JSON-адаптеры

Адаптер должен принимать GET-запрос с параметром q и возвращать JSON-массив либо объект results. Каждый результат: title, url, type (video или iframe), rating (необязательно), quality (необязательно), voice (необязательно). Сервер адаптера должен разрешать CORS.

Добавить JSON-адаптер

Укажите адрес JSON API, который поддерживает параметр ?q=поисковый_запрос. Это не URL страницы сайта и не адрес Lampa-плагина.

Настройки Cinema OS

Данные избранного и пользовательских источников сохраняются в памяти браузера телевизора.

API Кинопоиска

Для реального поиска и рейтингов нужен ключ стороннего Kinopoisk.dev. Официального открытого API Кинопоиска для этого нет. Ключ хранится локально в браузере телевизора.

Документация и получение ключа

Онлайн-движок Lampa

Cinema OS использует Lampa как отдельный движок онлайн-источников. Установите наш Lampa-модуль один раз в самой Lampa: Настройки → Расширения → Добавить плагин.

Адрес модуля: plugin.js

Модуль сторонний относительно Lampa. Онлайн-источники зависят от доступности их авторов, авторизации и совместимости браузера ТВ.

О приложении

Cinema OS MVP · самостоятельная веб-оболочка для MSX Player / LG webOS.

Текущая версия содержит рабочую навигацию, каталог-пример, поиск, карточки, избранное, настройки и запуск прямых видео-ссылок. Подключение коммерческих/сторонних каталогов требует отдельных адаптеров и законного доступа к их API.

Cinema OS · MVP · Работает как статическое веб-приложение, без собственного сервера.
